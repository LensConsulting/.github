- Прочие коды ([Массовое снятие паролей, префиллы по политикам и практикам, создание демо БД для демонстраций, обновление Статуса](https://github.com/LensConsulting/for-internal-use))


### Как установить себе нужный репозиторий с отчетами:
1. Заходим в нужный репозиторий (все ссылки на репозитории выше), копируем ssh-код: <img width="916" height="818" alt="image" src="https://github.com/user-attachments/assets/241d3816-db3f-469c-b070-13815de43a4d" />
2. Далее открываем терминал в папке, куда хотим установить репозиторий (рекомендуется сначала создать общую папку для всех кодов lens и клонировать все туда). В терминал вставляем:
```
git clone <ssh-код>
```
Например:
```
git clone git@github.com:LensConsulting/analytical-reports.git
```
Проверям, появился ли репозиторий в нужной папке. Готово!
